# Blood-Based Transcriptomic Signature for Alzheimer's Disease

This repository contains the full, reproducible analysis pipeline for the manuscript:

**"Identification of a Blood-Based Transcriptomic Signature for Early Detection of Alzheimer's Disease and Molecular Resemblance in Mild Cognitive Impairment"**

Author: Burhanettin Yalçınkaya — TÜBİTAK National Metrology Institute (UME), Kocaeli, Türkiye
Contact: burhanettin.yalcinkaya@tubitak.gov.tr

## Overview

The pipeline identifies a 100-gene blood transcriptomic signature distinguishing Alzheimer's disease (AD) patients from healthy controls, trains and compares Random Forest, Support Vector Machine, and Logistic Regression classifiers, and evaluates whether individuals with mild cognitive impairment (MCI) show AD-like molecular resemblance.

## Data

Both datasets are publicly available from NCBI Gene Expression Omnibus and are downloaded automatically by the script — no manual download is required:

- Discovery cohort: [GSE63060](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE63060) (145 AD, 104 controls, 80 MCI)
- External validation cohort: [GSE63061](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE63061) (139 AD, 134 controls)

Both series were generated by the AddNeuroMed Project on the Illumina HT-12 v4 platform.

## Usage

```r
source("AD_pipeline_FROZEN_REFERENCE_v2.R")
```

Running the full script will:

1. Download and preprocess both cohorts (quantile normalization, probe-to-gene annotation)
2. Identify the 100-gene differential expression signature (AD vs. control)
3. Train Random Forest, SVM, and Logistic Regression classifiers
4. Assess internal validity via out-of-bag estimation, 10-fold nested cross-validation, and bootstrap resampling
5. Perform external validation using a **frozen-reference (discovery-only) quantile normalization** scheme, so that the trained model can be applied to new, independently profiled samples — including a single new patient — without access to the full external cohort
6. Score MCI individuals for AD-like molecular resemblance
7. Run Gene Ontology enrichment analysis on the signature
8. Test additional confounders (self-reported ethnicity, hybridization chip batch) and visualize sample structure via PCA
9. Export all figures, supplementary tables, and a saved R workspace

## Reproducibility note

The script includes **two** external-validation pipelines, clearly labeled:

- The original **joint quantile normalization** pipeline (Blocks 15–19), retained for transparency and comparison. This approach normalizes the discovery and external cohorts together and is *not* applicable to a single new sample in isolation.
- The **frozen-reference normalization** pipeline (Blocks 15b–19b), which derives a fixed target distribution from the discovery cohort only and applies it independently to the external cohort (or to any new sample). This is the pipeline used for the results reported in the manuscript.

The frozen-reference target distribution is saved as `frozen_reference_target.rds` and can be reused to score new samples without rerunning the full pipeline.
